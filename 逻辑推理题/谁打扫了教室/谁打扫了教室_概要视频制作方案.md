# 《谁打扫了教室》概要视频制作方案

## 成片形式

面向小学生制作一条 **16:9 横屏图解短片，约 100～110 秒**。兔子妈妈以右上角头像出镜提问并读题，数字爸爸主导三轮检验、答案揭晓和验算。儿子听懂后主动提出快解，爸爸在他讲完后热情赞赏。 [题目与现有插图](谁打扫了教室.md)

## 新版配乐安排

四段配乐依次为：**《推理 (オリジナルヴァージョン)》→《小さな巨人》→《沈む夕陽（沉落夕阳）》→《対決のテーマ》**。

爸爸开始说「只剩第二种。打扫教室的是小华！」时，从《小さな巨人》用约 1 秒交叉淡化切入[《沈む夕陽（沉落夕阳）》](<bgm/沈む夕陽 (沉落夕阳).m4a>)，新曲从音源开头播放，覆盖完整揭晓与真假验算，旁白期间保持低音量。验算结束、儿子开始说「我发现还能更快」时，用约 1 秒交叉淡化转入《対決のテーマ》，延续到爸爸点赞收尾。换曲由台词触发，具体时间码以后续实测配音为准，衔接处不留音乐空白。

本轮仅更新文档，新版视频尚未生成。后续生成时同步调整配乐时间轴，重点试听两处新增交叉淡化，确认音乐连续、旁白清楚。

## 角色与节奏

| 段落 | 参考时长 | 画面与角色 |
| --- | ---: | --- |
| 教室谜题 | 12 秒 | 沿用[开场图](images/09-opening-question.svg)的左教室、右题面布局。兔子妈妈头像从「今天出一道推理题」持续展示到读题结束，三句原话随朗读依次亮出，留时间让孩子猜。此处时长待实测。 |
| 小天使该给谁 | 16 秒 | 父子短暂出镜。儿子跟着猜，爸爸引导把小天使轮流分给三个孩子，逐行亮出三种假设。 |
| 逐一检验 | 48 秒 | 三轮都由爸爸主导。每轮先看徽章，再从原话推出实际情况，停一下让孩子判断，最后显示结果。三轮依次是「矛盾、成立、矛盾」，儿子在旁跟着思考。 |
| 揭晓与验算 | 12 秒 | 爸爸揭晓小华打扫了教室，再把三句原话依次标成「假、真、假」，验算只有一人打扫、只有一人说真话。 |
| 儿子提出快解与爸爸收尾 | 待新增配音实测 | 儿子主动指出欢欢和乐乐的两句话正好相反，必有一真一假。因此小华一定说假话，也就是小华打扫了教室。用徽章互换配合讲解。儿子讲完后切到爸爸点赞收尾图，爸爸温和微笑点赞，说「漂亮！你找到两句正好相反的话，一下就推出来了！果然长江后浪推前浪！」儿子双手叉腰、略抬下巴，露出克制的小得意。 |

原五段参考时长合计 **104 秒**；新增儿子宣言和爸爸收尾后，正式总时长重新按配音实测。父子沿用半身立绘，以轻微进场、缩放和说话人高亮表现互动。 [爸爸立绘](../../digital-dad-math/characters/dad/dad-front-half-v2.png) · [儿子立绘](../../digital-dad-math/characters/son/son-front-half-v1.png)

数字爸爸用云健，儿子用云夏，两人保留原音高。兔子妈妈用晓晓成熟版，合成后降 2 个半音并恢复原时长。 [正式声线锁定记录](../../father-son-homework-comedy/tts/voice-lock.md)

## 制作与验收

- **Remotion + Chrome** 制作全片，复用教室图、父子立绘和推理 SVG。头像、徽章、原话和判断分别做成图层，三轮检验共用一套动画模板。 [蛞蝓科普视频制作记录](</Users/guhui/Githubs/block-world/course/video/蛞蝓科普视频制作记录.md>)
- 剧本定稿后用 **Edge TTS** 按角色配音，根据实际音频时长和字词边界对齐角色出场、徽章动作与字幕。画面与外挂 SRT 共用一条时间轴，提问停顿单独留时。 [视频制作流程攻略](</Users/guhui/Githubs/block-world/course/video/视频制作流程攻略.md>)
- 正式成片逐句试听，核对爸爸完整讲完主解法，儿子独立讲完快解，爸爸随后赞赏。用 **FFmpeg / ffprobe** 核验成片，交付 **1080p、30 帧 MP4 和外挂 SRT**。

## 15 秒无旁白样片

样片验证父子同框、提问停顿和徽章分配的节奏。父子复用数字书房同框立绘，分别加入错开的眨眼、轻微呼吸和头部小幅偏转。题面沿用图 2、图 3 的孩子头像、配色和徽章。 [小天使该给谁](images/08-choose-truth-teller.svg) · [三种真假组合](images/07-truth-assignments.svg)

| 时间 | 画面 |
| --- | --- |
| 0～2 秒 | 书房场景在左侧直接开场，爸爸和儿子并肩站立，镜头轻推。右侧同时展示三个孩子的头像、一枚小天使和两枚小恶魔。 |
| 2～5 秒 | 显示「小天使该给谁？」并停留 3 秒。三个头像上的徽章位都留空，让孩子先选。 |
| 5～12 秒 | 书房与题面淡出，切到全屏图解，在第 6、8、10 秒逐行亮出三种假设。小天使依次落在小华、欢欢、乐乐的头像旁，每行另外两人各戴一枚小恶魔。已完成的组合留在画面上，方便比较。 |
| 12～15 秒 | 三种组合同时定格，显示「接下来，逐一检查」。 |

用 **Remotion + Chrome** 制作，书房画面、头像、徽章和提示文字各自独立成层。样片导出为 **1920×1080、30 帧/秒、15 秒的无声 MP4**。

验收时用手机横屏完整播放一遍。确认父子同框，且没有挡住右侧题面，提问后完整留出 3 秒，每行恰好一枚小天使和两枚小恶魔，结尾三种组合都看得清楚。

样片已渲染。进入同目录的 `video/`，首次执行 `npm ci`，再执行 `npm run render` 可重新生成。 [播放本地样片](video/out/谁打扫了教室_15秒无旁白样片_v2.mp4)

已确认成片为 **1920×1080、30 帧/秒、450 帧、15 秒的 H.264 MP4**，无音轨且全片解码通过。按 640×360 的横屏尺寸抽查开场、父子分别眨眼、提问末帧、三轮徽章落位和结尾。父子在同一场景，右侧题面清楚，提问留白 3 秒，三轮徽章分配正确，末帧三行可同时读清。

后续制作进入逐句剧本、正式配音和成片阶段。

## 三轮推理图解修订

每轮固定按小华、欢欢、乐乐排列三行，每行包含原话、真假、文字推论和三个候选人标记。☑ 表示仅看这句话仍允许该人打扫，✖ 表示排除；真假徽章表示说话真假。每轮底部汇总三行共同候选人，依次为无、小华、无。第二轮与快解揭晓都在小华头像旁加扫帚，表示确认他打扫了。

后续视频需同步三行布局、逐行候选人标记、共同候选人汇总和答案扫帚。第一轮补充爸爸台词「小华说真话，所以小华没打扫」，并根据实测配音重新对齐后续动画、字幕与音乐。台本时间码为参考，现有视频时长是此前版本记录。

## 头像出镜的开场修订

使用[新版开场图](images/09-opening-question.svg)，右上角圆形头像复用兔子妈妈 v2 设定图左侧微笑形象，保留脸部和兔耳，头像下方标注「兔子妈妈」。开场白气泡为「今天出一道推理题」。

**完整台词**：「今天出一道推理题。放学后，小华、欢欢和乐乐三个人里，只有一人打扫了教室。小华说：“不是我做的。”欢欢说：“也不是我做的。”乐乐说：“是欢欢做的。”三句话里，只有一句是真的。谁打扫了教室？」

头像持续展示到读题结束。背景音乐沿用《推理 (オリジナルヴァージョン)》。未来视频改版需合成新增开场台词，按实测音长顺延时间轴，同步三句原话逐条亮出、字幕和音乐切换；上文成片时长记录对应此前版本。


## 快解与点赞插图素材

使用内置 imagegen 生成，父子身份、服装、身高差和暖色书房以现有父子同框图为参考。两张正式素材均为无文字横屏 PNG，人物位于左侧，右侧空黑板用于后续叠加图解或字幕。

- [儿子推理高光](images/10-son-deduction-highlight.png)用于儿子完整讲解快解。提示词要点为儿子稍靠前、托腮、食指指向右侧，呈现柯南式自信推理姿态；爸爸保持惊喜欣赏，服装和人物身份沿用原参考。
- [爸爸点赞收尾](images/11-dad-thumbs-up-ending.png)用于爸爸夸奖。提示词要点为爸爸看向儿子竖拇指，儿子双手叉腰略抬下巴。首版表情偏夸张，经一次修正将爸爸改为闭嘴温和微笑、自然眉眼，儿子改为睁眼浅笑、保留小得意；原始生成文件保留在工具输出目录，文档引用克制表情的正式版。

儿子完整讲完快解后切到点赞镜头。爸爸台词为「漂亮！你找到两句正好相反的话，一下就推出来了！果然长江后浪推前浪！」随后定格约 1 秒再淡出。《対決のテーマ》从快解延续到收尾。后续视频按新增台词实测音长，重新对齐切图、嘴型、字幕和音乐淡出。

## 下一步调整：儿子宣言与快解讲解

**儿子**：「我发现还能更快。真相只有一个！但是解法不止一种！」

停约半秒，儿子指向右侧开始分析：「先看欢欢和乐乐。欢欢说自己没打扫，乐乐说是欢欢打扫的。这两句说的是同一件事，意思正好相反，一定一真一假。题目说只有一句真话，这句真话已经在他们俩中间了。所以，小华说「不是我做的」一定是假话。反过来，就是小华打扫的！」

继续使用已落盘的推理高光图与克制版点赞图。宣言突出从爸爸的逐一假设法转向儿子的快解；具体分析依次呈现相反的两句话、一真一假、唯一真话已占用、小华说假话、答案扫帚。爸爸原有点赞台词保留。

下一步先按这版台词补录儿子片尾及爸爸夸奖，再按实测音长更新视频时间轴、字幕、嘴型、切图和音乐淡出，导出新版 MP4 与 SRT。本次仅更新文档，现有成片与配音尚未改版。
