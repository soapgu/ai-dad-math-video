# 《谁打扫了教室》分镜台本与配乐方案

面向小学生，16:9 横屏，目标时长约 **104 秒**。复用教室插图、父子同框书房和真假徽章。三段配乐依次使用 **《推理 (オリジナルヴァージョン)》→《小さな巨人》（小巨人）→《対決のテーマ》**。时间码为试配参考，换曲跟随台词和转场。

| 时间 | 分镜与台词 | 背景音乐 |
|---|---|---|
| **00:00–00:13** | **教室谜题。** 教室插图轻推，随旁白逐条亮出三个孩子的原话。**兔子妈妈（画外）**「放学后，三个人里只有一人打扫了教室。小华说『不是我做的』，欢欢说『也不是我做的』，乐乐说『是欢欢做的』。三句话里，只有一句是真的。谁打扫了教室？」 | **《推理 (オリジナルヴァージョン)》**随教室画面进入。旁白出现后压低音量，问完题后随画面切入书房而淡出。 |
| **00:13–00:20** | **父子同框。** 两人看向题面，右侧显示三个头像和空徽章位。**爸爸**「谁说真话，就给谁戴小天使。」 **儿子**「那小天使该给谁呢？」问完留 **3 秒**。 | **《小さな巨人》（小巨人）**随书房画面淡入。对话和提问留白期间保持低音量。 |
| **00:20–00:28** | **排出三种假设。** 小天使依次落在小华、欢欢、乐乐所在的三行，每行补齐两枚小恶魔。**爸爸（画外）**「轮流给三个人试试。每次一人说真话，另外两人说假话。真话照着听，假话反过来想。」 | 《小さな巨人》连续铺底。 |
| **00:28–00:45** | **第一轮，小华说真话。** 将欢欢和乐乐的原话分别连到相反的推论。**爸爸（画外）**「欢欢说『也不是我做的』，这句是假的，所以欢欢打扫了。乐乐说『是欢欢做的』，这句也是假的，所以欢欢没打扫。两条能同时成立吗？」并排显示两条推论，停 **2 秒**。**爸爸**「不能，第一种排除。」亮出「矛盾」。 | 《小さな巨人》低音量铺底，停顿时保持音量。 |
| **00:45–01:00** | **第二轮，欢欢说真话。** 小天使移到欢欢旁，逐条亮出推论。**爸爸（画外）**「欢欢说真话，那她没打扫。小华说『不是我做的』，反过来，就是小华打扫了。乐乐的话反过来，也是欢欢没打扫。三句话对得上，先留下这一种。」亮出「成立」。 | 延续《小さな巨人》。 |
| **01:00–01:13** | **第三轮，乐乐说真话。** 在小华和欢欢头像旁同时标出「打扫了」。**爸爸（画外）**「乐乐说真话，那欢欢打扫了。小华说的是假话，所以小华也打扫了。可题目允许两个人都打扫吗？」停 **2 秒**。**爸爸**「只有一人打扫，第三种也排除。」亮出「矛盾」。 | 延续《小さな巨人》，提问和停顿时维持低音量。 |
| **01:13–01:26** | **揭晓与验算。** 只高亮第二行，放大小华头像，给三句原话依次盖上「假、真、假」。**爸爸（画外）**「只剩第二种。打扫教室的是小华！验算一下，小华说自己没打扫，是假话。欢欢说自己没打扫，是真话。乐乐说是欢欢做的，是假话。只有一人打扫，也只有一句真话。」 | 《小さな巨人》铺到爸爸验算结束，随切回书房淡出。 |
| **01:26–01:44** | **儿子高光。** 回到父子同框，儿子转向爸爸。右侧并排放大欢欢和乐乐的原话，交换两句旁的真假徽章，再给小华落下小恶魔。**儿子**「爸，我发现还能更快！欢欢说自己没打扫，乐乐说欢欢打扫了。这两句正好相反，一定一真一假。唯一的真话已经在这里了，所以小华说『不是我做的』一定是假话。就是小华打扫的！」 **爸爸**看向儿子并点头。「漂亮！你找到两句正好相反的话，一下就推出来了！」 | **《対決のテーマ》**在儿子开口时入场，所选片段的重拍对准两句原话并排亮出的瞬间。推理时压低音乐，爸爸夸完后短暂抬起，随片尾淡出。 |

## 配音与混音

- 爸爸用云健，儿子用云夏，两人保留原音高。兔子妈妈用晓晓成熟版，降 2 个半音并恢复原时长。
- 人声与三首 BGM 分轨，先按实测人声锁定字幕和思考停顿，再对齐音乐进出点。《小さな巨人》作为一段连续音乐覆盖父子提问、三轮检验和揭晓验算。定剪前确认三首指定曲目的音源和发布授权。
- 先试配 **00:13–00:45**，验证《小さな巨人》在父子对话和第一轮检验下的音量。全片用手机外放检查两次换曲和三处关键台词「谁打扫了教室」「欢欢打扫了／欢欢没打扫」「一定一真一假」。
