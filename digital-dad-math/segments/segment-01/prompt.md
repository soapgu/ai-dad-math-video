# 第一段：认识减法（Seedance 2.0 Mini）

## 生成参数

- 模型：Doubao-Seedance-2.0-mini
- 时长：15 秒
- 画幅：16:9 横屏
- 生成方式：三张分镜参考图 + 一段 TTS 音频
- TTS 文件名：`segment-01-tts-v1.wav`；若网页不支持 WAV，则使用 `segment-01-tts-v1.mp3`

## TTS 口播

> 嗨，我是数字爸爸！桌上有 8 个苹果，拿走 3 个，还剩 5 个。8 减 3 等于 5。

TTS 使用亲切、活泼、清晰的成年男声，适合给小学一、二年级儿童讲解数学。语速自然、咬字准确，数字和算式读音清楚。音频总时长控制在 13.5～14.5 秒，开头保留约 0.3 秒自然准备时间，最后一句说完后保留约 0.5 秒安静收尾。不要加入背景音乐、音效或其他人声。

## 参考素材及用途

按以下顺序上传素材：

1. `references/01-start-v1.png`：0—3 秒开始画面，锁定人物、服装、背景、机位、空桌面和右侧空木盒。
2. `references/segment-01-action-v1.png`：3—8 秒核心画面，锁定桌面 8 个苹果的数量、排列和爸爸指向苹果的动作。
3. `references/segment-01-end-v3.png`：12—15 秒结束画面，锁定桌面剩余 5 个苹果、盒内 3 个苹果、人物姿态和黑板公式。
4. `segment-01-tts-v1.wav` 或 `segment-01-tts-v1.mp3`：唯一且完整的对白与节奏依据。

## 豆包网页操作顺序

1. 打开豆包视频生成页面，选择 Doubao-Seedance-2.0-mini。
2. 设置横屏 16:9、时长 15 秒。
3. 按“参考素材及用途”的顺序上传三张参考图和 TTS 音频。
4. 粘贴上方完整视频提示词，确认音频已作为参考输入启用。
5. 首次只生成一个版本，不同时提交多个变体。
6. 下载后命名为 `01_认识减法_v01.mp4`。
