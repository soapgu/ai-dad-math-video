# 第一段：认识减法（Seedance 2.0 Mini）

## 生成参数

- 模型：Doubao-Seedance-2.0-mini
- 时长：15 秒
- 画幅：16:9 横屏
- 生成方式：三张分镜参考图 + 一段父子混合 TTS
- 唯一音频：`tts/segment-01-tts-v1.mp3`
- 时间记录：`tts/segment-01-tts-v1-timing.json`

## 正式父子台词

- 数字爸爸：“嗨，我是数字爸爸！桌上有 8 个苹果，拿走 3 个，还剩几个？”
- 儿子：“还剩 5 个！”
- 数字爸爸：“对，8 减 3 等于 5。”

数字爸爸使用 `zh-CN-YunjianNeural` 云健男声，儿子使用已选定的 `zh-CN-YunxiaNeural` 云夏男声。音频为 24 kHz 单声道 MP3，实测编码时长 12.552 秒；不得加入其他人声、音乐或音效。

## 参考素材及用途

按以下顺序上传：

1. `references/01-start-v1.png`：锁定开场人物、服装、背景、固定机位、空桌面和右侧空木盒。
2. `references/segment-01-action-v1.png`：锁定中段桌面 8 个苹果的数量、排列及爸爸指向苹果的动作。
3. `references/segment-01-end-v3.png`：锁定结尾桌面 5 个苹果、盒内 3 个苹果、父子姿态和黑板公式。
4. `tts/segment-01-tts-v1.mp3`：全片唯一、完整且不可更改的对白与节奏依据。

## 豆包网页操作顺序

1. 选择 Doubao-Seedance-2.0-mini，设置 15 秒、16:9 横屏。
2. 依次上传开始图、动作图、结束图，再上传 `tts/segment-01-tts-v1.mp3`。
3. 确认音频参考已启用，粘贴上方完整提示词。
4. 首次只生成一个版本，下载后命名为 `01_认识减法_v01.mp4` 并保存到 `videos/`。

## 验收清单

- [ ] 视频为 15 秒、16:9，完整播放父子三轮台词。
- [ ] 父子只在自己的音频区间开口，没有同时张嘴、抢话或错角色口型。
- [ ] 苹果严格遵循“空桌面 → 8 个 → 桌面 5 个 + 盒内 3 个”。
- [ ] 3 个苹果移动过程清楚，无复制、融合、闪烁或凭空消失。
- [ ] 父子相貌、服装、身高比例、背景和固定机位全程一致。
- [ ] 人物嘴部、手部和肢体没有明显畸变。
- [ ] 结尾公式清晰稳定、无乱码，12.497～15 秒保持约 2.50 秒稳定画面。

若公式或中文文字生成失败，下一版改为空黑板并在后期添加；若双人口型失败，只强化说话人时间区间或减少同期动作，不改变已确认的 TTS、台词和苹果数量逻辑。
