# 最小开场样片（Seedance 2.0 Mini）

## 生成参数

- 模型：Doubao-Seedance-2.0-mini
- 时长：5 秒
- 画幅：16:9 横屏
- 参考图：`references/intro-start-v1.png`
- 唯一音频：`tts/intro-tts-v1.mp3`
- 唯一口播：`嗨，我是数字爸爸`

## 生成 TTS

在项目根目录执行以下命令，以临时隔离环境安装依赖并生成音频：

```bash
python3 -m venv /private/tmp/ai-dad-math-tts-venv
/private/tmp/ai-dad-math-tts-venv/bin/python -m pip install -r digital-dad-math/intro-minimal/requirements.txt
/private/tmp/ai-dad-math-tts-venv/bin/python digital-dad-math/intro-minimal/generate_tts.py
```

脚本固定使用 `zh-CN-YunjianNeural` 云健中文男声，语速设为 `-15%`，只输出一条 MP3，不加入背景音乐、音效或其他人声。

## 豆包网页操作顺序

1. 选择 Doubao-Seedance-2.0-mini，设置横屏 16:9、时长 5 秒。
2. 先上传 `references/intro-start-v1.png`，再上传 `tts/intro-tts-v1.mp3` 并启用音频参考。
3. 粘贴以下提示词；首次仅生成一个版本。
