# 使用AI助力信创国产化操作系统图形化软件开发的实践

## 视频目标

制作一条接近 2 分钟的成果展示视频，讲清图形化软件开发中的业务痛点、软件的核心功能、AI 的具体做法与创新点，以及实践带来的实际价值。成片沿用本页标题。

## 汇报时长

- 成片控制在 1–2 分钟。
- 现场汇报总时长控制在 5–8 分钟，包含视频播放和 PPT 讲解。

## 内审要求

- 检查画面、字幕和旁白中的具体项目、企业及单位名称，统一用「XX」代替或做脱敏处理。客户信息和公司数据也须脱敏。
- 使用原创素材，避免出现第三方 IP、商标和标识。
- 成片保留用途声明「本视频仅限本次活动内部交流展示，不作为任何商业用途」。

## 待补充内容

- **业务场景**：待补充开发场景和要解决的业务痛点。
- **已有构思**：待补充视频的叙事思路和呈现方式。
- **可展示成果**：待补充可用于演示的功能和能够说明实际价值的成果。

活动征集海报仅作为背景参考。
